# AyuPredict
AI-powered healthcare prediction system that predicts diseases using Machine Learning and provides Ayurvedic treatment recommendations along with nearby hospital suggestions using Random Forest and KNN algorithms.
## Features
- Disease prediction using Machine Learning
- Ayurvedic treatment recommendations
- Nearby hospital recommendation system
- User-friendly healthcare interface
- High prediction accuracy using Random Forest
- Location-based hospital suggestions using KNN

## System Modules
### 1. Disease Prediction Module
Predicts possible diseases based on user symptoms using the Random Forest algorithm.

### 2. Ayurvedic Recommendation Module
Provides Ayurvedic remedies and treatment suggestions for predicted diseases.

### 3. Hospital Recommendation Module
Uses KNN to recommend nearby hospitals based on user location input.
